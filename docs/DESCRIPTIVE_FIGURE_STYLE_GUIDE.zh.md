# 描述性图风格规范（main）

本项目 `main` 分支的描述性 PNG 统一遵循以下规范：

## 1. 风格目标
- 整体风格参考 Building and Environment / Origin 一类论文图
- 白底、浅灰网格、低饱和度配色
- 图面克制，避免花哨渐变和高饱和撞色

## 2. 主图模板
描述性图默认采用：
- 主面板：`box + mean ± 95% CI + 轻量 jitter`
- 右侧：统计摘要框

不再把多种风格（box / jitter / violin）并列当作主结果图批量导出。

## 3. 配色
两组对比时，优先使用：
- Low / 第一组：`#6E8FA8`
- High / 第二组：`#D89B72`

单组图使用：
- `#9FB8C9`

边线/中位线/均值标记使用：
- `#2F3B46`

## 4. 几何约束
- 箱体更窄，避免重叠
- 组间 dodge 必须明显大于箱体宽度
- jitter 仅作为弱辅助层，不能压住箱线主体

## 5. 统计信息展示
每张主图右侧必须给出真实统计结果摘要，至少包含：
- `n`
- `M`
- `SD`

如有需要，可在 csv 中进一步查 `95% CI`、`median`、`min/max` 等。

## 6. 设计原则
- 图既要好看，也要能直接服务结果写作
- 避免“只能看趋势、不能读结果”的图
- 避免箱体重叠、散点抢戏、标注拥挤
